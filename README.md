## 🚀 Proyectos destacados

### 🛒 Golden Point — E-commerce de artículos deportivos

**Proyecto integrador final de la Tecnicatura | Desarrollo colaborativo — Grupo QWERTY123**

Aplicación web de comercio electrónico para equipamiento deportivo. Integra un **frontend con React** y una **API REST con Java y Spring Boot**, conectados a una base de datos MySQL.

- Registro e inicio de sesión, autenticación mediante **JWT** y autorización según roles.
- Catálogo con filtros, detalle de productos, carrito y gestión de pedidos.
- Integración de pagos de prueba con **Mercado Pago**.
- Panel administrativo para productos, catálogo, pedidos y usuarios.
- Notificaciones por correo, avisos de reposición de stock y configuración de la tienda.
- Documentación de la API con Swagger/OpenAPI y despliegue mediante servicios en la nube.

**Tecnologías:** Java 21, Spring Boot, Spring Security, Spring Data JPA, React, JavaScript, MySQL, Maven, Docker, Mercado Pago, Brevo y Cloudinary.

**Participación registrada en GitHub:** trabajo en el backend, incluyendo autenticación JWT, catálogo, cotización del carrito, ajustes de tienda, notificaciones y configuración de integraciones.

🔗 **[Ver repositorio de Golden Point](https://github.com/HotCode2025/Qwerty123-ProyectoIntegrador-Ecommerce-CuartoSemestre)**

### 🚢 Batalla Naval — Juego con interfaz gráfica y persistencia

**Proyecto integrador de Programación III | Tercer semestre**

Juego de Batalla Naval desarrollado en Python, con versiones de **consola** e **interfaz gráfica con Pygame**, aplicando programación orientada a objetos y separación de responsabilidades.

- Lógica de tablero, barcos, disparos y puntuación.
- Interfaz gráfica interactiva realizada con Pygame.
- Almacenamiento de resultados en **SQLite**.
- Ranking de jugadores e historial de partidas.

**Tecnologías:** Python, Pygame, SQLite y POO.

🔗 **[Ver proyecto Batalla Naval](https://github.com/feermza/batalla_naval)**
